# 软件、硬件、联调、测试工作区

## 布局

左侧保留四个主入口，共用工程树和设备绑定；中央显示当前工作页；底部输出按需展开；右侧在属性与 Agent 之间切换。工作页标签按当前主工作区显示，不再把全部功能挤在同一排。

| 工作区 | 主要内容 |
| --- | --- |
| 软件 | 源码、编译与下载器、解析脚本、自定义控件、内置/外部 Agent |
| 硬件 | 硬件文件、KiCad XML 网表、引脚/信号映射、PCB 模型与姿态 |
| 联调 | 串口、波形、节点、实时电路图、指令库、协议与仪器、CAN |
| 测试 | 源码编译/测试、设备自动测试、报警、录制回放、运行日志 |

顶部“文件、编辑、视图、工具、窗口、设置”集中提供低频操作。“窗口”可直接打开波形、协议与仪器、CAN、姿态独立窗口，继续共享当前设备服务。设置中的常用功能按四个工作区分组。

## 节点一键配置与无拖动操作

进入“联调 → 节点编排 → 一键配置”，选择通道直通、多通道平滑、ADC 换算、双通道比值、三轴模长、合成传感器或突变测试模板。模板读取实际通道名，可手动指定 1..16 通道。

模板只替换草稿，可以撤销；点击“应用到数据”后才影响当前设备的处理图。测试模板不会连接或向设备发送数据。草稿按设备和项目保存，支持 JSON 导入/导出；上限 64 节点、128 条连线、16 个输出通道。

| 操作 | Windows/Linux 快捷键 |
| --- | --- |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |
| 复制节点 / 全选 | Ctrl+D / Ctrl+A |
| 添加 / 表单连接 | N / C |
| 自动排列 / 适应画布 | L / F |
| 应用 / 删除 | Ctrl+S / Delete |
| 移动节点 | Tab 聚焦、Enter 选择、方向键移动 |

macOS 使用对应的 Cmd 修饰键。“连接节点”弹窗可直接选择源节点、输出口、目标节点和输入口；循环、端口不存在及重复输入会被拒绝。右侧可查看并断开单条连线，不必精确拖拽小圆点。菜单“编辑 → 键盘快捷操作”可查看快捷键。

“测试与代码”支持 Arduino、C99、Python 和 JavaScript/Node 导出。Python/JS 是本机数据生成/处理示例，不会自动连接串口，不保证真实采样时钟。生成值通过同一节点处理逻辑的测试数据对比。

## 硬件与软件关联

1. 先添加工程并确认当前设备。
2. 在硬件工作区导入 KiCad 导出的 XML 网表（`.xml` 或 XML 格式 `.net`）。
3. 从器件引脚创建映射，填写 GPIO、单位、有效范围、数据通道及源码位置。
4. 保存后切换实时电路图，查看所选器件附近的实际网表连接和通道读数。
5. 点击源码位置跳转到对应文件与行；属性面板继续显示绑定设备和工程。

网表导入保留位号、物理引脚、引脚名称和网络名称。目录清单可发现 KiCad、PDF、PCB/3D 文件，但发现文件不等于已经解析其电气内容。当前没有直接编辑 `.kicad_sch`、`.kicad_pcb` 或执行 EDA 的功能。

导入连接、手工映射和遥测数据分别标识。实时值只来自已绑定通道，断连或采样过期会显示过期状态，不伪造每个网络的电压。数据来自主机接收时刻，不能替代设备硬件时间戳。

映射持久化到软件数据目录，按工程和设备隔离；保存携带版本，冲突时保留本地草稿供确认。不会修改原始 KiCad 工程。

## 反馈测试

在“参数下发与反馈测试”填写命令、预期 ACK、等待时间和信号范围，可生成自动测试草稿。生成草稿不会发指令；需在测试工作区审阅后运行。

顺序为发送、匹配响应、等待、检查新有效采样。处理失败产生的新原始帧不能拿旧值冒充反馈成功。设备切换、工程变化、断连和原有任务锁仍受检查。

没有收到反馈只说明需要排查：可能是绑定、协议、固件处理、采样、供电或线路等原因，不能自动认定“线接错了”。实际电气仿真、PDF/图片自动识图、自动配置 MCU 引脚、ERC/DRC、SWD/JTAG 调试尚不在此次实现范围。

## 语言与编译

CodeMirror 增加 Python/MicroPython、Rust、Go、Java、C#、Lua、Shell、PowerShell、ARM 汇编、Verilog、CMake、JSON/YAML/XML/TOML 等高亮，可按文件名识别或手动切换。高亮支持不等于相应语言具有 LSP 或目标 MCU 编译器。

增加 Cargo/Go 工程识别与固定构建命令，以及 Python unittest、Node test、Go test、Cargo 测试编译入口。Cargo 使用离线锁文件构建；测试编译不会执行板上测试或自动烧录。目标工具必须事先安装，缺失时报告实际错误。

原有 Arduino、PlatformIO、ESP-IDF、CMake/CTest、GCC、Keil、IAR 和诊断跳转继续使用。当前源码窗格仍为只读，修改沿用 Agent 提案、差异确认和备份记录。
