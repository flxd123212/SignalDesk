# Agent 运行与故障恢复

适用版本：0.1.9，2026-11-16。

## 保存与恢复

桌面版使用 Electron 异步 safeStorage，将 API 配置、密钥、会话记录、原生模型续接数据及计划整体加密保存到用户数据目录的 `agent-state.json`。写入采用临时文件替换；普通状态更新合并写入，保存设置会等待写入完成，关闭最后一个窗口也会等待保存。不会把 API Key 放进前端偏好、公开状态、会话导出或审计日志。

- 每个工作区独立存储，保留设备标识、会话 ID 与选中会话；不会因为删除其他设备导致重启后串绑。
- 单会话保留最近最多 300 条、512 KiB 可见记录，超限移除最早记录。需要长期归档时可导出 Markdown，包括计划、可见工具输入/结果及调用来源。
- 模型续接保留最近最多八轮完整问答，连同历史摘录共计最多 128000 字符。移出的轮次只保留有界的请求、当时回复与工具名称摘录，不保留原始快照、工具结果或私有推理。摘录不是重新验证后的结论，也不等于无限记忆；展开会话设置可查看、重置上下文可一并清除。
- 关闭或异常退出后恢复为空闲/中断状态，连续分析不重启，写文件/串口/工具链提案不自动恢复执行。之前的文件修改记录仍可查询，新修改需要重新读取 SHA256。
- 外部 Agent 的历史恢复为只读会话；授权令牌仍在重启后失效，需要重新创建连接。
- “清除密钥”删除当前设备各会话保存的密钥；“清空 Agent 会话”删除该会话保存的记录和上下文；“重置模型上下文”仅清除模型续接历史。
- 加密不可用的独立 Node 服务仅保存不含密钥的设置、文本历史和计划。原生私有推理及签名不落盘，后续只续接文本摘要式历史；界面明确显示密钥只在内存。已加密文件不能解密时保留原文件并显示错误，不覆盖成空记录。
- 本地保存不等于跨电脑同步。加密数据依赖系统账户；数据迁移前应导出需要的会话，目标电脑重新配置密钥。

## 模型来源与上下文

模型在正文中自称 Claude、DeepSeek 或其他名称，不能证明实际调用的是该模型。运行时系统消息会提供本次请求的模型 ID、API 格式和主机名，要求按配置事实回答，不从协议名称、旧聊天或自我介绍推断厂商。

每次成功获得有效回复或工具调用时，记录请求模型、接口返回模型、实际请求 URL、API 格式、请求/响应 ID、结束原因、耗时与接口提供的输入/输出 token 计数。Chat、Responses、Anthropic 使用响应 `model` 字段，Gemini 使用 `modelVersion`。缺失字段显示未提供，不以配置名或生成文本填补；不同 ID 只提示可能的别名或路由映射，不直接断言调用了错误模型。接口提供的 ID 也不是对底层模型权重的独立验证。

- 回复与工具事件下方可展开调用记录并复制；测试接口结果也区分请求与返回模型。
- 日志和 Markdown 会话导出保留调用来源，之后修改模型配置不改写旧回复的记录。
- 只记录允许的元数据，不保存完整请求头、API Key 或私有推理。失败请求沿用错误日志，不冒充成功响应记录。
- 展开会话与分析设置可查看保留的轮数、字符数和移出的轮数，点击“重置模型上下文”保留可见记录和待执行提案。该数值是历史数据字符量，不是模型 token 窗口或余额。
- 保存后测试、读取模型列表及重置上下文会核对设备、会话和工程，切换后拒绝过期请求。

## 回答模式

DeepSeek 官方 Chat Completions 接口的自动模式显式发送 `thinking.type=disabled`，优先得到可用正文。预设使用 8192 tokens、120 秒；已有自定义上限仍按用户值发送。

设置中可以选择快速回答或深度思考。启用深度思考时预填至少 16384 tokens、180 秒，并可选择低、高、最高思考强度。用户仍可手动调整。推理与正文共享输出预算，不能保证所有任务都在预算内完成；仅返回推理时给出明确原因，不将推理文本伪装成最终回答。

只对 DeepSeek 官方主机发送协议对应的思考参数。Chat 使用 `thinking` / `reasoning_effort`；Responses 使用 `reasoning.effort`，自动/快速为 `none`、最高为 `xhigh`；Anthropic 使用 `thinking.type=adaptive` 和 `output_config.effort`，快速模式显式 disabled。切换 DeepSeek 协议会联动地址，详见 [AI 接口配置](AI_PROVIDERS.md)。

## 终端式界面

会话采用连续输出、等宽字体和紧凑工具事件。底部独立输入区支持多行请求，Ctrl+Enter 发送；中文输入法确认不会误触发送。

- 输入 `/` 显示快捷任务，方向键选择、Enter 填入，Escape 关闭。`/analyze`、`/review`、`/test`、`/explain`、`/patch` 对应数据分析、代码审查、测试方案、项目说明、修改提案；选择任务只填入请求，不自动发送。只读模式不提供修改任务。
- C/C++ 与 JavaScript 代码块支持语法高亮和独立复制。模型文本以 React 文本节点展示，不解释 HTML。
- 顶部可暂停或恢复自动跟随输出，方便翻看旧记录；会话以 Markdown 导出，包含正文与可见工具事件，不导出 API Key 或私有推理数据。
- 会话选择和新建始终可见，连续分析、子代理与步数配置通过展开设置访问；项目、差异和执行面板仍可按需打开。
- 保留完整页面与 IDE 右侧分栏两种布局。
- 工具箱展示 18 个工具及只读/确认执行状态；每次工具调用展示状态、耗时、有界参数与结果，相关源码可直接跳转。展开会话设置可搜索历史记录。
- 新增 `/plan`、`/continue`、`/diagnose`、`/changes`。多步骤任务可显示 Agent 计划，计划状态由模型维护，不能代替实际编译或设备验证。
- 界面动画用于新消息、弹窗、菜单、工具详情和运行反馈，不重播恢复的历史。支持全局关闭，并遵循系统 `prefers-reduced-motion`。

## 工作模式与工具

- **只读分析**：读取设备快照、列出和读取源码、搜索源码、查看本会话最近的构建结果。服务端拒绝修改、串口发送与构建提案，不依赖模型自觉遵守。
- **建议与补丁**：额外允许创建差异、指令和工具链提案；实际写文件、发指令和执行仍由原有权限与确认流程控制。
- 源码搜索为不区分大小写的字面文本搜索，返回相对路径、行号和摘要，沿用工程目录和扩展名限制。一次最多扫描 2 MiB、返回 60 条，明确报告跳过或截断；不是全仓库无限搜索。
- 构建结果来自当前会话的真实构建任务，返回状态、退出码和末尾最多 12000 字符，不把编译通过说成硬件测试通过。
- 新增项目概览、文件名检索、按行读取、结构化编译诊断、最近修改和差异查询。源码浏览与局部补丁支持最多 8 MiB 的 UTF-8 文件；按行读取每次最多 200 行、16000 字符，单行最多 1000 字符且截断有标记，沿用工程目录限制。附带超过 32000 字符的文件时只发送明确标注的开头片段、字节数和完整 SHA256，Agent 按需读取其他行段，不必拆分用户工程。整文件替换仍限 96 KiB，较大文件必须使用局部补丁；单次差异超过 256 KiB 或计算超时则拒绝，要求缩小修改范围。
- 局部补丁工具验证当前文件 SHA256 和唯一文本目标，生成差异等待确认，保留无关文本与行尾格式；旧校验值、重复目标、路径越界均拒绝。
- 报文查询只有勾选“附带原始日志”才向模型提供，筛选当前设备缓存的最近 RX/TX，每条最多 512 字节、最多 30 条，不发送任何字节。外部 MCP 不公开此工具。
- 只读工具同步提供给具有 read 权限的外部 Agent；修改提案仍要求 propose，实际执行继续要求相应权限。

## 运行控制

- 显示上下文读取、等待模型、工具执行、重试、完成、失败和停止状态，以及当前步数。
- 对 HTTP 429、500、502、503、504、529 最多额外重试两次，遵循 Retry-After，默认间隔 1、2 秒。服务器要求等待超过 30 秒时直接报告错误，避免长期占用。鉴权、错误参数、空正文及截断工具调用不自动重试。
- 重试只重发失败的模型请求，不重新执行已完成的本地工具。模型生成可能计费，服务商的具体计费规则仍适用。
- 停止可以取消等待重试；失败或停止后可点击“重试上次请求”，重新获取当前设备上下文，已有提案保留。
- 默认最多 8 次模型步骤，可在展开的分析设置中改为 2..20；最后一步关闭工具并要求总结已完成、未完成和待执行事项。预算用尽或计划仍有未完成项时显示暂停，不能把它当作全任务完成。输入框上方的“继续任务”会在明确点击后开始新的有界轮次；核对设备、会话与工程，原只读任务不升级权限，不自动启用原始日志。
- 静态工具第三次相同调用不执行，返回纠偏信息并进入不再调用工具的总结步骤；参数按深度排序比较，计划更新不会掩盖重复，实时快照/构建状态轮询不按静态读取处理。达到输出上限的工具调用不执行。
- 四种 API 格式保留原生完整问答与工具调用/结果配对；模型接口失败或停止时也保存已完成配对，批次中未记录完成结果的调用明确标为“执行未验证”，不伪造成功或作为孤立调用续接。暂停任务及历史摘录随存档保存，重启不会自动运行。旧版本只有计划而没有继续参数时，恢复为只读继续入口。
- 正文中的非代码示例 DSML 工具标记会被明确报告为格式异常，不解析成指令，不标记为成功。本地状态会显示等待模型的秒数；这不代表 token 流式响应或模型端进度。
- 历史与摘录总预算为 128000 字符，不是服务商 token 窗口保证。当前任务、新读取文件及本轮新工具结果另计；单轮过大时原生轮次会被移出，只留下标明不完整的摘录。当前没有自动调用模型生成的语义压缩。
- Responses 的原生 output 和工具结果、Anthropic 内容块、Gemini thought signatures、Chat 的 reasoning_content 各自按协议续接，不再从界面正文重建工具历史。私有续接数据仅保存在运行内存及桌面加密存档，不进入界面状态、审计日志、明文存档或导出；更换模型、地址、API 格式、思考模式/强度、密钥、工程或重置上下文时清除。
- 当前请求附带最新提案状态，区分待执行与已执行。上下文重置不会代替提案确认或执行。
- 主会话后续追问会收到最近三个子代理的任务、结果与完成/失败状态，每条结果最多 8000 字符并标注截断；子代理文本仍作为不可信观测数据。切换模型/工程或重置上下文时移除这些摘要，界面原记录保留。

当前不是完整 OpenCode 集成，没有加入无限循环、自主烧录、任意 shell 自动执行或工作区之外的写入。
