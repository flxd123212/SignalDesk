# Agent 运行与故障恢复

适用版本：0.1.2，2026-11-15。

## 回答模式

DeepSeek 官方 Chat Completions 接口的自动模式显式发送 `thinking.type=disabled`，优先得到可用正文。预设使用 8192 tokens、120 秒；已有自定义上限仍按用户值发送。

设置中可以选择快速回答或深度思考。启用深度思考时预填至少 16384 tokens、180 秒，并可选择低、高、最高思考强度。用户仍可手动调整。推理与正文共享输出预算，不能保证所有任务都在预算内完成；仅返回推理时给出明确原因，不将推理文本伪装成最终回答。

只对 DeepSeek 官方 Chat 接口发送这些扩展参数，避免破坏其他兼容服务。

## 终端式界面

会话采用连续输出、等宽字体和紧凑工具事件。底部独立输入区支持多行请求，Ctrl+Enter 发送；中文输入法确认不会误触发送。

- 输入 `/` 显示快捷任务，方向键选择、Enter 填入，Escape 关闭。`/analyze`、`/review`、`/test`、`/explain`、`/patch` 对应数据分析、代码审查、测试方案、项目说明、修改提案；选择任务只填入请求，不自动发送。只读模式不提供修改任务。
- C/C++ 与 JavaScript 代码块支持语法高亮和独立复制。模型文本以 React 文本节点展示，不解释 HTML。
- 顶部可暂停或恢复自动跟随输出，方便翻看旧记录；会话以 Markdown 导出，包含正文与可见工具事件，不导出 API Key 或私有推理数据。
- 会话选择和新建始终可见，连续分析、子代理与步数配置通过展开设置访问；项目、差异和执行面板仍可按需打开。
- 保留完整页面与 IDE 右侧分栏两种布局。

## 工作模式与工具

- **只读分析**：读取设备快照、列出和读取源码、搜索源码、查看本会话最近的构建结果。服务端拒绝修改、串口发送与构建提案，不依赖模型自觉遵守。
- **建议与补丁**：额外允许创建差异、指令和工具链提案；实际写文件、发指令和执行仍由原有权限与确认流程控制。
- 源码搜索为不区分大小写的字面文本搜索，返回相对路径、行号和摘要，沿用工程目录和扩展名限制。一次最多扫描 2 MiB、返回 60 条，明确报告跳过或截断；不是全仓库无限搜索。
- 构建结果来自当前会话的真实构建任务，返回状态、退出码和末尾最多 12000 字符，不把编译通过说成硬件测试通过。

## 运行控制

- 显示上下文读取、等待模型、工具执行、重试、完成、失败和停止状态，以及当前步数。
- 对 HTTP 429、500、502、503、504、529 最多额外重试两次，遵循 Retry-After，默认间隔 1、2 秒。服务器要求等待超过 30 秒时直接报告错误，避免长期占用。鉴权、错误参数、空正文及截断工具调用不自动重试。
- 重试只重发失败的模型请求，不重新执行已完成的本地工具。模型生成可能计费，服务商的具体计费规则仍适用。
- 停止可以取消等待重试；失败或停止后可点击“重试上次请求”，重新获取当前设备上下文，已有提案保留。
- 默认最多 8 次模型步骤，可在展开的分析设置中改为 2..20；最后一步关闭工具并要求总结已完成、未完成和待执行事项。
- 连续三次相同工具及参数会停止重复循环。达到输出上限的工具调用不执行。
- DeepSeek 会话在内存中保留最近最多三个完整问答及其工具续接数据，总上限约 512000 字符。私有推理不进入界面状态、审计日志或磁盘；更换模型、地址、思考模式、密钥、工程或清空会话时清除。

当前不是完整 OpenCode 集成，没有加入无限循环、自主烧录、任意 shell 自动执行或工作区之外的写入。
