# ESP32-S3-DevKitC-1 v1.1 模型精度记录

## 样例型号

采用 **ESP32-S3-DevKitC-1 v1.1、ESP32-S3-WROOM-1 模块**作为参考。
这不代表所有带 ESP32-S3 的开发板；双 Type-C、不同针数、WROOM-1U 外置天线等版本不能套用。
该模型由 Three.js 几何体与文字纹理构建，不是官方 STEP，也未宣称达到制造精度。

## 依据与精度

| 部分 | 当前依据与限制 |
| --- | --- |
| PCB 板框 | 官方尺寸图标注 62.74 x 25.40 mm；不包含突出的模块天线部分 |
| 排针 | 左右各 22 针，2.54 mm 间距；针中心距板边 1.27 mm |
| J1 / J3 名称与顺序 | 官方 v1.1 用户指南引脚表；不同模块的内存占用/复用限制仍需核对 |
| U4 | 官方原理图 ESP32-S3-WROOM-1；屏蔽罩、天线纹理、焊盘外形近似 |
| U3 | 官方原理图 CP2102N-A02-GQFN28；封装与位置近似 |
| U2 | 官方原理图 SGM2212-3.3XKC3G/TR；外形近似 |
| J2 / J4 | 双 Micro-USB，分别为 UART bridge 与芯片 USB；壳体细节近似 |
| SW1 / SW2 | BOOT / RESET，按官方布局近似放置 |
| D6 | SK68XXMINI-HS RGB LED，v1.1 为 GPIO38；早期版本为 GPIO48，不可混用 |
| 板厚、圆角、器件高度、被动元件 | 视觉近似，未按封装数据表逐一核验 |

因此这个版本适合检查板型、连接器布局、元件名称、引脚标签及姿态显示；
**不适合外壳开孔、装配干涉、生产、走线检查或电气连接验证**。
导出 GLB 的根缩放把内部毫米几何转换成米，但未知机械公差不会因此变成已知。

## 元件交互

可选择或点击 U4、U3、U2、D6、J2/J4、SW1/SW2、J1/J3 及单个排针。
右侧/下方显示器件名称、参考位号和引脚标注；可手动绑定接收数据通道，
在模型覆盖层显示当前值。不会因为选中 GPIO 就假定固件已经配置该引脚。
