# 屏幕设计器

从「工具 → 屏幕设计器」进入。草稿按设备和工程保存，也可以导出 JSON 带到另一台电脑。选择模块时核对控制器、分辨率和总线，尺寸相同的模组可能采用不同控制器。

| 预设 | 驱动 | 接口 | 原生像素 |
| --- | --- | --- | --- |
| 0.96″ / 0.91″ OLED | SSD1306 | I²C | 128×64 / 128×32 |
| 1.3″ OLED | SH1106G | I²C | 128×64 |
| 1.14″ / 1.54″ / 2.0″ IPS | ST7789 | SPI | 135×240 / 240×240 / 240×320 |
| 2.8″ TFT | ILI9341 | SPI | 240×320 |

1. 在画布中添加文字、进度条、色块、按钮或透明热区。拖动定位，属性栏可按像素修改尺寸。选中画布后方向键微调。
2. 底图支持 PNG、JPEG 和最多 48 帧的 GIF。「识别热区」按图像中的连续色块生成候选矩形。在属性栏核对区域并指定目标页，然后进入「交互预览」。
3. 选择 I²C 地址或与板卡接线相符的 SPI 引脚。有电阻触摸控制器时选择 XPT2046，使用实际屏幕测得的触摸原始范围校准生成草图中的 X_MIN、X_MAX、Y_MIN、Y_MAX。其他输入驱动可以调用 `uiTap(x,y)` 或 `uiShow(page)`。串口发送 ASCII `0` 到 `7` 也可访问已有页面。
4. 使用「生成并打开编译工程」，确认板卡 FQBN 后进入构建与测试。独立工程内的草图与下载的 `.ino` 相同。Arduino 核心及库由选定工具链管理。草图顶部列出需要安装的库。
5. 上板后对照首页、四角方向、色序、每个按钮和动图节奏。示例的数值和进度是设计常量。连接实时传感器需要固件逻辑。

## 容量与测量

设计器量化后的像素直接进入 Arduino 草图，内嵌文字与图片。默认逐帧比较原始像素与游程编码的字节数，选择占用较小的一种。静态页面只在切换时重画，动图使用各帧的时间间隔。单色 OLED 使用显示缓冲，彩屏复用一行 RGB565 缓冲。素材压缩节省 Flash，全屏传输时间仍由像素数、驱动和总线决定。

| 默认双页示例 | Arduino 目标 | 编译结果 |
| --- | --- | --- |
| SSD1306 128×64 | Uno | 15,470 B Flash，547 B 静态 RAM，运行时显示缓冲另需 1,024 B |
| ST7789 240×240 | Uno | 35,330 B，超过可用的 32,256 B Flash |
| ST7789 240×240 | Mega 2560 | 36,144 B Flash，937 B 静态 RAM |

## 从设计草案生成界面

打开「设计助手」，选择多级菜单、状态切换、图像热区或自然语言。前三种在本机生成。自然语言模式使用当前设备配置的模型，只发送需求和屏幕规格。检查草案中的每一页，选择是否设为开机页，点击「应用到设计」。撤销可一次移除整份草案。

对已导入的截图或 GIF 使用「图像热区」时，程序从首帧提取候选区域，生成有返回按钮的详情页。选中热区可以拖动位置和尺寸，更改跳转目标和串口事件。预览会显示 `UI:事件名`，生成的固件在实际点击时通过串口发出同样的文本。

单色屏可在「屏幕接口与编码」启用灰阶有序抖动。彩屏 GIF 从第二帧起只传输变化像素的外接矩形，循环回首帧时恢复整页。XPT2046 的轴旋转和四个原始坐标端点可直接在面板中设置，端点值以实际触控屏测量为准。

界面与交互设计参考 [AiDoGUI 官方使用文档](https://aidogui.com/docs) 和 [AiDoGUI Designer](https://github.com/aidogui/aidogui-designer)。开发工具与验证流程参考 [Yoma](https://github.com/yoma-embedded/yoma)。SignalDesk 此导出目标使用 Arduino 和 Adafruit 显示驱动。
