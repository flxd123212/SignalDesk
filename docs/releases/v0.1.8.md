# SignalDesk 0.1.8

## 教程与使用体验

- 新增内置帮助中心，11 套任务式教程覆盖入门、软件、硬件、联调、测试与进阶工具；不需要联网阅读。
- 首次启动显示可关闭的轻量入门提示，不强制打开弹窗；进阶教程默认收起。
- 每一步提供操作说明、预期结果和风险边界，可直接定位对应页面或设置，返回后继续原步骤。
- 自动保存课程位置和完成记录；支持重学、教程搜索、当前页面 F1 帮助和“设置 > 学习与帮助”。
- 功能搜索增加添加项目、连接设置、设置、精简模式和教程快捷入口，减少寻找菜单的步骤。
- 教程操作不会自动发送设备指令、运行工具链、烧录或调用付费模型；阅读和完成教程不代表设备测试通过。

保留软件、硬件、联调、测试四个工作区和独立仪器窗口；包含 0.1.7 的大文件源码浏览与 Agent 局部补丁修复。本次为本地构建，不自动发布 GitHub。
