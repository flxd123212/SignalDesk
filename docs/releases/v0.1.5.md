# SignalDesk v0.1.5

本次相对 GitHub 上的 v0.1.2 累积发布，也包含此前本地 0.1.3、0.1.4 的更新。

## Agent 与会话恢复

- 桌面端加密保存 API 配置与密钥，多设备会话、当前选择、任务计划和工具上下文重启恢复。
- Agent 扩展至 18 个工具，支持项目概览、文件检索、分段读源码、构建诊断、历史差异、报文查询和局部补丁提案。
- 新增工具调用详情、源码跳转、会话搜索、任务计划、继续任务快捷操作；完善模型来源记录与多轮上下文。
- 完善 DeepSeek 多种 API 格式适配，保留修改、指令发送、工具链执行的权限与确认流程。

## 启动与动画

- 新增电路信号启动动画，真实加载状态、跳过/Esc、异常重试和预览。
- 原生桌面窗口在首帧就绪后显示，减少空白闪屏；启动页加载失败时关闭未显示的窗口。
- 丰富页面、侧栏、底部面板、标签、菜单、按钮、状态与 Agent 消息动效；保持示波器的暂停与量程状态。
- 柔和/灵动两种风格，全局及启动动画独立开关，遵循系统减少动态效果偏好。

## 个性化

- 自定义主题色，支持取色器与 HEX；按钮文字随颜色亮度调整。
- 自定义纯色或本地图片背景，实时预览、填充方式、模糊、遮罩和恢复默认。
- 背景单独保存在本机，主题和动画偏好重启恢复，不上传图片。

## Windows 文件

- `SignalDesk-Setup-0.1.5-x64.exe`：安装版，支持目录选择及桌面/开始菜单快捷方式。
- `SignalDesk-Portable-0.1.5-x64.exe`：免安装单文件版。
- `SHA256SUMS.txt` 与 `release-manifest.json`：文件大小及 SHA256 校验信息。

本轮通过 11 项界面专项、TypeScript/Vite 构建、桌面与打包 EXE 检查、背景/API/会话重启恢复及免安装启动验证；Agent 后端沿用 0.1.4 的 146 项通过记录。本轮未重跑全部界面与后端测试。验证结果见 `docs/VALIDATION.md`，使用方法见 `docs/USER_GUIDE.md`。

Windows 安装包和免安装包未签名，升级前正常退出旧版。图片、API 密钥、会话记录与本机配置不随源码或安装包上传。
