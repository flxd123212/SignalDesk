# SignalDesk v0.1.1

Windows x64 嵌入式开发与调试工作台，整合工程、串口、波形、工具链与 Agent。

## 下载

- `SignalDesk-Setup-0.1.1-x64.exe`：推荐安装版，可选择目录并创建桌面和开始菜单快捷方式。
- `SignalDesk-Portable-0.1.1-x64.exe`：免安装单文件版，启动时解压运行环境；设置保存在当前用户目录。
- `SHA256SUMS.txt`：两个发行文件的 SHA256 校验值。
- `release-manifest.json`：文件大小、版本对应文件名及校验信息。

两种程序均包含 Electron/Node.js，无需另装 Node.js。目标设备的驱动、编译器、SDK、器件包和烧录工具需自行安装。

## 本版内容

- Windows 一体化标题栏，合并软件菜单和窗口顶部区域，保留原生窗口按钮。
- 默认离线启动，取消启动时自动运行模拟设备。
- 后台串口检测和新设备弹窗，支持选择工程、仅绑定或绑定并连接。
- 唯一 USB 身份匹配 COM 号；芯片识别信息不足时保留待确认状态。
- 多设备工作区、串口终端、波形与频谱、节点处理、协议测试、日志与报警。
- 工程导入、C/C++ 源码高亮、编译测试、GCC/Keil/IAR 等工具链接入。
- 内置 Agent、修改前后对照，以及带可选权限的 MCP、CLI、HTTP 外部 Agent 接口。

## 验证与限制

- TypeScript/Vite 构建与 109 项后台测试通过。
- 桌面启动、安装版和免安装版已验证。
- 完整界面回归 45 项中 44 项通过；1 项受连接或截图进程中断影响，未获得完整通过结果。
- 串口插拔主要使用 Mock 验证，尚未完成真实开发板持续采样与下载验证。
- 波形和频谱分析依赖设备上传的数据，不能替代硬件采样前端；高速波特率支持取决于硬件与驱动。
- 当前发行文件未做代码签名，未提供自动更新、macOS 或 Linux 安装包。

使用方法、功能范围及验证记录见仓库 README 和 `docs/`。
