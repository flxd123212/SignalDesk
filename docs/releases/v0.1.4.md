# SignalDesk v0.1.4

## API 与会话恢复

- 桌面版加密保存 API 设置与密钥，正常退出后重启无需重新配置。
- 恢复多设备会话、当前选择、模型工具上下文、任务计划；设备编号固定，删除其他设备后也不会串绑。
- 修复最后一个窗口关闭时未等待后台保存的问题。损坏或无法解密的存档保留并显示错误。
- 重启不自动恢复执行任务或串口指令；外部 Agent 会话以只读记录恢复，连接令牌仍失效。

## Agent 工具与界面

- 扩展至 18 个工具：新增项目概览、文件检索、分段读源码、编译错误定位、历史与差异、报文查询、任务计划、局部补丁提案。
- 工具调用可展开参数/结果，显示耗时并跳转相关源码；支持任务计划、会话搜索与权限状态工具箱。
- 新增继续任务、计划、编译诊断、历史审查快捷任务。
- 消息、弹窗、菜单和工具状态增加轻量动画；可关闭并遵循系统减少动态效果设置。

持久化边界、独立 Node 服务行为及数据迁移说明见 `docs/AGENT_RUNTIME.md`。自动验证结果见 `docs/VALIDATION.md`。

本次通过 146 项后端测试、6 项 Agent/设置界面专项、TypeScript/Vite 构建、打包 EXE 回归、三次实际桌面重启恢复与免安装版启动检查。AI 请求使用本机夹具验证，未使用个人密钥访问线上模型。

Windows x64 安装包与免安装包未签名。升级前正常退出旧版；不会主动关闭正在使用的设备会话。首次使用新版仍需要填写一次此前未保存的 API Key，之后会加密保留。
