# SignalDesk 0.1.10

本版为 v0.1.6 之后的累计更新。Windows x64 安装版与便携版由同一份源码构建。

## 工作台与使用体验

- 四个工作区调整为顶栏切换，共享工程树；设备和连接信息合并到一行，保留属性与 Agent 分栏、独立仪器窗口和精简模式。
- 新增银灰仪器台外观，代码、波形和终端保留深色内容区；可在「设置 → 主题与背景」切回深色石墨风格，并自定义主题色、背景及动效。
- 实时监测的读数区和波形区重新布局；通道趋势来自最近采样，连续采集时收起无关的触发参数。无采样时提供连接和打开录制入口，不伪造测量数据。
- 项目源码、引脚映射、构建输出的空状态增加对应的操作入口；帮助中心提供任务式教程和 F1 当前页面帮助。

## 嵌入式开发

- 大文件源码浏览上限 8 MiB；Agent 处理大文件使用分段读取、局部补丁、原文件哈希校验及确认后的写入，避免将片段误当完整文件覆盖。
- 新增 OLED/TFT 图形化设计器，支持页面、触摸区域、图片/GIF、单色抖动与差分帧编码，并导出 Arduino 显示代码。屏幕型号、驱动、触摸校准和真实帧率仍需对应硬件验证。
- 加强 USB 设备识别、工程绑定和工具链检测，提供官方工具下载入口；缺少编译器时不会宣称工程已通过编译。

## Agent 与安全

- Agent 到达本轮步骤上限时标记为暂停，用户可以按需继续；上下文重建、历史摘要与计划进度支持恢复。外部只读会话不会因恢复被授予写入权限。
- 增加工具调用记录和诊断信息；文件写入、串口发送、工具链执行继续由各自权限和确认机制控制。API 密钥保存在本地服务，不随日志导出。

## 验证与平台

- Windows x64 安装程序和免安装 EXE 随本次发行附上 SHA256 校验文件。本次构建未签名；如系统显示安全提示，请核对发行地址及哈希。
- Linux 和 macOS 适配代码及原生 CI 构建仍在仓库中，但本次仅发布已在 Windows x64 本机验证的程序包；其余平台不能使用 Windows 安装包。
- 不自动连接真实设备，不自动烧录或调用付费模型；屏幕画面、串口测试与工具链输出必须结合实际目标板单独确认。
