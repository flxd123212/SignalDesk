# SignalDesk v0.1.6

2026-11-15。本次发布 Windows x64 安装包和免安装版；Linux/macOS 适配代码已加入，安装包尚待原生构建和验证。

## 四个主工作区

- 软件、硬件、联调、测试四个入口，共用工程树，中央显示当前内容。
- 右侧在属性和 Agent 之间切换，底部输出按需展开。
- 顶部文件、编辑、视图、工具、窗口和设置菜单集中操作；仪器可用独立窗口。
- 窄窗口自动收起侧栏，工程绑定弹窗在缩放时保留内容和主题，支持继续保存。

## 节点与硬件关联

- 七种节点配置模板，支持表单连线、键盘移动、撤销重做、自动排列、草稿保存及 JSON 导入导出。
- 节点测试代码支持 Arduino、C99、Python 和 JavaScript。
- KiCad XML 网表导入，关联器件、引脚、数据通道和源码位置，显示绑定遥测与连接关系。
- 生成命令、ACK 和采样范围组成的反馈测试草稿，由用户审阅后执行；不会自动向设备发送测试命令。

## 语言与跨平台

- 增加 Python/MicroPython、Rust、Go、Lua、汇编、Verilog 和常见配置文件的高亮。
- 接入 Cargo/Go 工程识别与固定构建命令，以及 Python、Node.js、Go 和 Cargo 的测试入口。
- 补充 Linux/macOS 窗口、快捷键、串口路径、工具查找与进程组取消处理。
- 新增 Linux AppImage/deb、macOS DMG/ZIP 的原生 CI 构建流程；Linux/macOS 尚未完成原生构建和实物验证。

## 更新文件与验证

- `SignalDesk-Setup-0.1.6-x64.exe`：Windows 安装包。
- `SignalDesk-Portable-0.1.6-x64.exe`：Windows 单文件免安装版。
- `SHA256SUMS.txt`、`release-manifest.json`：文件校验信息。

功能合并后的后端回归为 160 项通过、2 项 POSIX 测试在 Windows 跳过；完整界面回归 59 项通过。安装与打包检查记录见 [验证记录](https://github.com/flxd123212/SignalDesk/blob/v0.1.6/docs/VALIDATION.md)。

Windows 打包程序和单文件免安装版均已通过启动验证，并完成从 0.1.5 到 0.1.6 的本机安装更新验证；安装后的程序通过隔离的 API/会话重启恢复、原生串口模块与多窗口检查。

升级沿用现有用户数据目录；工程、主题、API 配置和会话不打入安装包。硬件图展示网表与遥测关联，不是电气仿真；尚未提供原生 EDA 编辑、ERC/DRC 或 SWD/JTAG 调试。

Windows 发行文件未做代码签名。升级前正常退出旧版，再运行安装包。
