# SignalDesk 0.1.12

这版让工程开发、台架联调和验收测试可以在同一个工作区完成。

## 更新内容

- **Agent 项目任务**支持整理需求和验收条件、跟踪计划、查看改动及测试证据。工具可持续运行直到返回结论，也可以主动停止或续接。执行权限按工程和操作类型设置。
- **工程与源码**新增快捷操作、源码检索与定位、固件体积与内存报告、崩溃地址解析，并补充 STM32、STM8、CH32、STC 和 GCC 交叉编译示例。
- **台架与联调**增加工程实验室、SCPI 仪器接入、数字信号捕获与解码、CAN 数据统计、设备参数下发与回读对照。
- **现场测试**支持报警前后数据留存、烧录后固件版本验证、长稳测试及结果导出。屏幕设计器增加渲染结果对照。

## 下载

- `SignalDesk-Setup-0.1.12-x64.exe` 是带桌面和开始菜单快捷方式的 Windows 安装版。
- `SignalDesk-Portable-0.1.12-x64.exe` 是 Windows 单文件免安装版。
- `SHA256SUMS.txt` 提供两种未签名程序的 SHA-256 校验值。

真机烧录、仪器通信和屏幕显示效果需在目标设备上验收。部分仪器驱动、编译器和 SDK 需要单独安装。
