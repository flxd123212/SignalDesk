# SignalDesk v0.1.3

## Agent 模型来源与上下文

- 修复旧校验错误拦截 DeepSeek Responses。Chat Completions、Responses 和 Anthropic Messages 三种格式支持地址联动、分别适配思考参数；添加 Flash / Pro 预设模型。

- 每条 AI 回复和工具事件可展开调用记录，区分请求模型与接口返回模型，显示地址、API 格式、请求/响应 ID、耗时、结束原因及 token 用量；支持复制、日志与会话导出。
- 接口未返回模型 ID 时明确显示未提供。生成文本的自我介绍不作为来源凭据，运行时提示要求按配置事实回答。
- 四种 API 格式完整保留工具调用历史，切换模型或接口时隔离原生签名与推理数据。
- 主会话后续请求收到有界的子代理任务、结果和完成/失败状态，避免丢失协作结论；上下文重置时清除。
- 增加历史上下文用量、移出计数和独立重置，保留聊天记录与待执行提案。保存后测试、模型列表和重置操作拒绝过期设备/会话/工程。
- 沿用现有权限、修改确认和设备保护，不增加自主烧录。
