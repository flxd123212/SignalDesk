# SignalDesk v0.1.2

Windows x64 Agent 修复与体验更新，2026-11-15。

## 下载

- `SignalDesk-Setup-0.1.2-x64.exe`：安装版，包含桌面和开始菜单快捷方式。
- `SignalDesk-Portable-0.1.2-x64.exe`：单文件免安装版。
- `SHA256SUMS.txt` / `release-manifest.json`：文件大小与 SHA256 校验信息。

## 修复与新增

- 修复 DeepSeek 默认思考消耗输出预算导致无最终正文的问题：增加自动、快速回答、深度思考及强度选择；预设使用 8192 tokens / 120 秒。
- 正确保留 DeepSeek 工具续轮与后续问答所需的私有上下文，不在日志或界面输出推理内容。
- Agent 增加只读分析与建议/补丁模式、实时执行阶段、有限重试、停止等待和手动重试。
- 新增源码字面搜索、定位行号以及真实构建结果读取工具。
- 保护连续重复调用，拒绝执行被截断的工具请求；达到步骤上限后关闭工具并总结进度。
- 保留多设备工程绑定、原有执行权限、修改差异与历史记录。
- Agent 改为终端式连续输出界面，加入斜杠任务、代码块高亮/复制、输出跟随控制和会话 Markdown 导出，适配完整页面和 IDE 分栏。
