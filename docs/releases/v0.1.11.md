# SignalDesk 0.1.11

本次为 v0.1.10 的外观修复版，保留原有功能和本地设置。Windows x64 安装版与便携版由同一份源码构建。

## 修复

- 修复自定义图片或纯色背景与「银灰仪器台」主题叠加时，顶栏、工作区切换、项目侧栏和读数卡片出现深色底搭配深色字、内容难以辨认的问题。
- 顶栏、侧栏、属性面板和读数卡片恢复稳定表面色；背景仍显示在中央工作区，中央画布增加对比遮罩。
- 「深色石墨」主题的半透明背景效果保持不变；新增测试覆盖两种主题、自定义背景、属性面板和移动端。

## 验证与平台

- Windows x64 安装程序、免安装 EXE 与 SHA256 校验文件随发行版提供。本次程序包未签名；请从本项目发行页面下载并核对哈希。
- 本次没有发布 Linux / macOS 程序包；没有自动连接真实设备、烧录固件或使用付费模型。硬件相关能力仍须以目标设备实测为准。
