# SignalDesk 0.1.7

## 大文件源码修复

- 修复超过 96 KiB 的 Arduino/C/C++ 等源码打开后空白的问题，UTF-8 单文件浏览上限提升至 8 MiB。
- 保留语法高亮、搜索、行号跳转和函数大纲，优化大纲行号计算。
- Agent 附带大文件时自动提供有限行段、文件大小和完整 SHA256，不再因超过 32000 字符直接失败；按需读取其他行段。
- 大文件使用局部补丁生成前后差异，保留用户确认、过期校验拒绝、原文件备份和修改记录。整文件替换仍限制为 96 KiB，避免把片段误写成完整文件。

修复不需要拆分用户工程，不修改原工程源码、API 配置或会话记录。8 MiB 是浏览和局部补丁的文件上限，不代表模型能一次接收完整文件，也不代表工程已通过编译或硬件测试。
