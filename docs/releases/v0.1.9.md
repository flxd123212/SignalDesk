# SignalDesk 0.1.9

## Agent 停顿与恢复

- 到达步骤预算后显示“暂停”，而非误报整个任务已完成；输入区新增继续任务与本轮步数预算。
- 继续时保留原任务和完整工具证据，重建最新设备/工程上下文，不自动提权或执行写入、串口、工具链操作。
- 异常或取消后保留已完成的调用/结果配对，旧版本未完成的计划也能恢复手动继续入口。
- 异常 DSML 工具标记不再被当作成功正文，不会解析执行这些标记。
- 最近原生上下文由三轮增加到最多八轮；在原有字符总预算内，为移出的轮次保留有界历史摘录，支持查看、保存与清除。
- 重复静态工具调用进入安全收尾；增加等待秒数，区分暂停、错误、停止与完成。

## 研究与边界

参考用户提供的 Bigfish 0.1.2 和 DeepSeek Harness 0.1.0-rc.6 本地副本，核对记录见 [Bigfish Agent 研究](../BIGFISH_AGENT_REVIEW.md)。本轮未集成整个 Harness，也未实现结构化用户问答或任意 shell 自动执行。

Windows 安装包与便携版随本地构建提供；本轮不会自动覆盖旧安装、重启用户会话或发布 GitHub。线上模型效果仍需用户自己的服务商验证。
