# 仪器与源码调试

从「工具 → 工程实验工具」选择台架、功耗、BLE、CAN 或探针。项目源码工具栏另有编辑、符号查询与调试入口。绑定信息按工程和设备保存在当前浏览器或桌面应用的本地配置中。

| 任务 | 操作与条件 |
| --- | --- |
| 保存源码 | 在工程树打开文件，点铅笔。用「查看增删」比较草稿，按 Ctrl+S 或 Cmd+S 保存。保存会核对打开时的 SHA256。发生冲突时，可先复制草稿，再刷新文件取回外部版本。 |
| 查看编译诊断、定义和引用 | 将 clangd 加入 PATH 或 `SIGNALDESK_TOOLCHAIN_PATH`。打开 C/C++ 文件，把光标放在符号上，点击源码工具栏的 clangd 按钮。可指定工程内的 `build/compile_commands.json`，CMake 可使用 `-DCMAKE_EXPORT_COMPILE_COMMANDS=ON` 生成。点击结果跳至对应文件和行。Arduino 工程需提供与实际预处理环境匹配的编译数据库。 |
| 实板断点 | 启动与芯片匹配的本机 GDB Server。STM32F103 可用 CMSIS-DAP、SWD 和 OpenOCD 的 `target/stm32f1x.cfg`。CH32V003 使用 WCH-LinkE、WCH RISC-V 调试服务及匹配的交叉 GDB。双击源码行号，选架构、带调试符号且与板上固件匹配的 ELF 和服务端口，然后连接、设断点、继续。暂停后可查看局部变量、寄存器、调用栈或跳回源码。 |
| ADC 校准 | 连接实板并配置数值协议。选择万用表 VISA 资源，将 ADC 输入与表笔接到同一信号，固件通道以 V 上报。填入允许误差，可选固件标记、启动标志和采样命令。勾选电源控制的等效操作是填入可控电源资源。此时运行会按电源现有设定开启输出，结束、取消或失败后尝试关闭。报告记录两端的时间、单位、读数及误差。 |
| 功耗 | 在「功耗时间轴」发现并绑定 JS110 或 JS220，选择采集时长。拖动起止位置查看选区内累计能量的差值，可保存基线供下次采集比较。已连接设备的串口接收事件与电流统计按主机时间对齐。时间精度受 USB 与主机调度影响。 |
| BLE | 扫描附近设备，选择地址，枚举服务，选择特征句柄。支持读、HEX 写入和限时订阅。要送入波形、报警和录制，选择空闲设备标签并勾选波形选项，1、2、4 字节通知按无符号小端解析，其他长度保留原始 HEX。 |
| CAN | 从「CAN 分析 → 适配器采集」打开。Linux 先配置 SocketCAN 接口的仲裁与数据码率。Windows 安装 PCAN 驱动，选择通道、码率和 FD 模式。选择监测 ID 与超时门限可检查报文间隔。采集支持经典与 FD 数据、扩展 ID 和 BRS 标记，可载入 DBC 并导出完整报告。每次任务保留前 12000 条记录及总计数。 |

## 设备联调与诊断

- **故障现场**　在报警页给设备配置断开、断流、范围或突变规则。触发后点「查看现场」，可查看触发前 10 秒、后 20 秒的原始收发、通道数据、最后命令、最后样本与重新连接的时刻。可导出 JSON 或把选取的记录提交给当前设备的 Agent。数据保存在本机 `incidents` 目录，滚动保留 64 个现场。高流量时记录会标明截断或丢弃。
- **在线调参**　在工程实验工具选择「在线参数与读回」。每个参数可绑定写命令、读回命令、回报字段、范围和传感器通道。例如写 `SET TEMP {value}`，读 `GET TEMP`，从设备返回的 JSON 行 `{"config":{"target":45}}` 读取 `config.target`。界面分别呈现请求值、设备回报与采样曲线。
- **启动版本核对**　在芯片与固件页展开「构建、烧录与启动版本核对」。绑定运行串口，填写工程产物相对路径、地址、预期版本和设备版本协议，点击「构建并预览烧录」。预览会显示镜像 SHA256 和产物是否在本次构建中更新。确认目标并写入后，工作台从下载器日志判读校验结果，通过运行串口核对版本。仅在启动时发送版本的固件，也可配置固件已有的查询命令，再次取得版本回报。
- **长稳测试**　在「台架与 ADC 校准」编辑自定义步骤，展开「长时间稳定性测试」，选择循环次数或运行时长。仅收发命令的步骤可直接使用串口或 TCP。设置可控电源时，每轮按台架设置上电和关闭。报告保留通过数、超时、最长无接收时间、启动与响应耗时以及首次失败现场。选择历史基线可并排查看，最近 12 次报告按设备与工程保存。运行期间保持本地服务开启，重启后可以查看已保存的进度。

台架面板中的「自定义台架步骤」可保存并重复执行以下格式的序列。`expect` 等待当前连接收到对应文本，`measure` 通过绑定的仪表检查读数，任一步失败时终止并保留已测结果。

```json
[
  {"type":"send","text":"READ_ADC"},
  {"type":"expect","text":"ADC_READY"},
  {"type":"wait","ms":100},
  {"type":"measure","unit":"V","min":3.1,"max":3.5}
]
```

## 可选依赖

适配器在本机 Python 3 环境中运行。将 `SIGNALDESK_LAB_PYTHON` 设为所用虚拟环境的 Python 可执行文件。以下命令在工程根目录运行。

```sh
python -m pip install -r server/bench-requirements.txt
```

VISA 支持系统 VISA 和 `@py` 后端。可发现的资源及 USB、LAN 接口取决于该后端与系统驱动。ADC 用例使用 `MEAS:VOLT:DC?`，电源使用 `OUTP ON/OFF`，接入前核对设备编程手册。蓝牙访问使用操作系统的 GATT 权限。打开仪器不需要更改当前工程的源码。
